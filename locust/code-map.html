Starter project

Code map

The project keeps the reconstruction scripts together with the website and local asset code written for this starter project.

LOCUST run

Input: Metashape export, 45 source images; 44 registered images retained.

Camera check: COLMAP sparse model; 38 training views and 6 held-out views.

Masks: SAM2Matting propagation, alpha threshold 0.10 by default, with a seed frame and bounding box.

Training: native resolution, 50,000 iterations, 2,000,000 Gaussian cap, MRNF strategy, SH degree 3, refine every 200 steps until 28,500, evaluation and save at 50,000, PPISP enabled, controller disabled.

Delivery: the centered 50K PLY was converted to a 16.7 MB SOG file for browser loading. The large PLY remains local only because GitHub rejects files over 100 MB.

Files written for this starter: site/index.html, site/styles.css, site/masking.css, site/app.js, site/code-map.html, scripts/recenter_ply.py, start-site.ps1, and the README files.

Files copied from the reconstruction workflow: pipeline/run_masks.py, pipeline/run_reconstruction.sh, pipeline/training_config.json, and pipeline/supersplat_output_browser_server.py.
